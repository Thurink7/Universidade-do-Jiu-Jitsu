# Universidade do Jiu-Jitsu

Site institucional da **Universidade do Jiu-Jitsu**, desenvolvido para apresentar a academia, sua filosofia de ensino, equipe e modalidades de treinamento.

## 1. Tema escolhido e público-alvo

O tema escolhido foi o desenvolvimento de um site institucional para uma academia de Jiu-Jitsu. O site é destinado a pessoas interessadas em iniciar a prática da modalidade, alunos que desejam conhecer melhor a academia e praticantes que procuram informações sobre professores, turmas e horários de treinamento Aproveitando também do reconhecimento da já bem-sucedida na área .

## 2. Problema ou necessidade

A ausência de um canal digital organizado, dificultando o acesso às informações da academia por pessoas interessadas em treinar. O projeto busca centralizar essas informações em um único ambiente, facilitando o conhecimento da instituição e o contato com a equipe.

## 3. Planejamento do projeto

O desenvolvimento foi planejado a partir de referências visuais colhidas no instagram da academia e prototipada no Figma, separando como paleta de cores:
#fff Textos sobre fundos escuros e botões
#000 Fundos escuros, botões e rodapé
#080808 Textos e detalhes
#222222 Efeito hover dos botões
#555555 Textos secundários
#c5b900 Detalhes da section equipe

Fontes escolhidas:
'Montserrat': Textos gerais, parágrafos e conteúdo principal
'Teko': Navegação, títulos de cards, botões e textos de destaque
'Bebas Neue': Títulos principais, chamadas e cabeçalhos de seções

## 6. Como executar o projeto

### Pré-requisitos

É necessário ter o [Node.js](https://nodejs.org/) instalado no computador.

### Passo a passo

1. Clone o repositório ou baixe os arquivos do projeto.

2. Abra a pasta do projeto no terminal.

3. Instale as dependências:
   npm install

4. Inicie o servidor de desenvolvimento:
   npm run dev


5. Acesse no navegador o endereço exibido pelo terminal, normalmente `http://localhost:5173`.
